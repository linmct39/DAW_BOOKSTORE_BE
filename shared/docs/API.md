# Bookstore API (Books Service)

Base URL: `http://localhost:8001`

## Categories

- `GET /categories` (query: `q`, `skip`, `limit`)
- `POST /categories`
- `GET /categories/{id}`
- `PUT /categories/{id}`
- `DELETE /categories/{id}`

## Books

- `GET /books` (query: `q`, `category_id`, `category_name`, `skip`, `limit`)
- `POST /books`
- `GET /books/{id}`
- `PUT /books/{id}`
- `DELETE /books/{id}`
